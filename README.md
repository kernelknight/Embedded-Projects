# Embedded Projects

Linux embedded-systems projects, device-driver experiments, and hardware
interface code.

## Projects

| Project | Description |
| --- | --- |
| `Linux_Device_Drivers/HD44780_Char_LCD` | Linux character device driver for HD44780-compatible LCD modules over DB-25 parallel-port wiring or a vendor-specific USB bridge |

## Build Notes

Kernel modules must be built on Linux with matching kernel headers installed.
Each project folder includes its own README, wiring notes, and test guidance.
